# 思考与实践

[English](README.md) · [返回首页](../README.zh.md)

这些文章讨论[原则](../principles.zh.md)在具体条件下怎样使用，不是额外的一套常驻规则。一个设想值得讨论，不代表现在就适合采用。

| 文章 | 定位与问题 |
|---|---|
| [与 agent 一起工作](ai-collaboration.zh.md) | 实践方法：怎样提供上下文、委托工作并验证结果？ |
| [与 agent 协作的团队](ai-native-teams.zh.md) | 经验综合：除了工具，团队还需要改变什么？ |
| [平台工程](platform-engineering.zh.md) | 条件性实践：归属、状态、生命周期和采用路径怎样影响平台设计？ |
| [具体工作约定](working-defaults.zh.md) | 本地选择：我会采用哪些流程和工具约定，又会在什么时候替换它们？ |
| [面向自主交付的工程](autonomous-delivery.zh.md) | 提案与思想实验：长期自主交付可能需要怎样的环境？研究与价格有明确时间背景，不是实时建议。 |

这里区分的是适用范围和把握程度，不是重要性。一个判断在不同环境中仍有充分依据，可以提炼为原则；过时的做法则应更新或退出，不能因为反复写过就变成通则。
