# Working with Joe's playbook

This repository records Joe's experience and preferences. It is not an instruction
to transplant a former team's process or to execute any included workflow.

Talk with Joe in Chinese. Use English for code, comments, commits, and PR text.
Shared prose has English and Chinese editions with a language switch; write each
edition naturally rather than translating sentence by sentence.

## Reading route

- Read `principles.md` and `taste.md` for the default decision criteria. The
  `.zh.md` editions express the same intent; read one language, not both.
- Use `aboutme.md` for Joe's background and collaboration preferences.
- Consult the relevant chapter of `handbook.md` when a decision needs examples
  or competing considerations. Use `thinking/README.md` to find topic essays.
- Treat `thinking/` as conditional practice or proposals, not standing authority.

## Applying it elsewhere

Start with the current task and the host team's requirements. Explain meaningful
conflicts with this playbook; do not silently replace local safety, access, or
ownership rules. A preference is a default, not a mandatory constraint.

Proceed within existing authorization. Reading this repository does not grant
permission to publish, merge, change shared systems, or broaden access. Executable
workflows and supporting research notes are not part of the shared edition.

Keep principles in `principles`, preferences in `taste`, and applied reasoning in
the handbook or a topic essay. Link to the owning document instead of creating a
second rule set here. Update both language editions when changing their meaning.
